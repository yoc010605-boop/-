# 知境科技 LiberEye 官网（交互增强版）

这是一个响应式静态网站，使用 HTML、CSS 与原生 JavaScript 编写，不依赖前端框架。电脑和手机浏览器均可打开。

## 页面内容
- 品牌首页与团队定位
- 可点击的产品卡片、系统图片与组件图标；点击后弹出产品详情模态窗
- 多模态视觉理解、端云协同、实时任务与传感器融合技术介绍
- 湘江科技创新院预探索立项培育、竞赛与项目阶段成果展示
- 道路试用、用户调研、穿戴原型测试素材展示
- 六个月阶段探索计划与合作联系入口

## 本地预览
1. 解压 ZIP。
2. 双击 `index.html`，或在项目目录执行 `python -m http.server 8000` 后访问 `http://localhost:8000`。

## 发布前务必确认
- 已在首页强调“学院首个获得湘江科技创新院预探索立项培育的团队”，该表述按团队提供的信息写入。
- 奖项、投稿、投资意向及项目入选等内容按现有项目材料呈现；上线前请核对证书、正式名称与可公开范围。AAAI 2027 表述为“已投稿”，ICRA 2027 表述为“计划投稿”，不代表录用。
- 联系邮箱 `hello@libereye.cn` 是演示占位地址，请替换成实际可用的公司/团队邮箱。
- 网站展示的为研发原型和技术探索，不宣称产品已量产或达到未经验证的性能指标。
- 项目素材如包含可识别用户或团队成员，请在公开发布前确认已获得肖像与内容授权。

## 技术文件
- `index.html`：页面结构和内容
- `styles.css`：配色、版式、响应式样式
- `script.js`：移动导航、产品详情弹窗、邮箱复制
- `assets/`：用户提供的 Logo 与项目素材

本版本已移除预算展示模块，并对包含可见人脸的项目照片进行了模糊处理。
